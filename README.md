# 🚀 Placement GPT – AI-Powered Placement Preparation Platform

**Placement GPT** is an AI-powered platform designed to help students prepare for campus placements and job interviews. It provides intelligent assistance for technical interviews, HR interviews, resume preparation, coding practice, and career guidance.

Our goal is to make placement preparation smarter, easier, and more accessible for every student.

## ✨ Features

- 🤖 **AI Interview Preparation** – Practice technical and HR interview questions with AI.
- 📄 **Resume Analysis** – Get suggestions to improve your resume.
- 💻 **Coding Assistance** – Practice programming questions and understand solutions.
- 🎯 **Personalized Learning** – Get preparation guidance based on your skills.
- 🗣️ **HR Interview Practice** – Improve communication and interview confidence.
- 📚 **Technical Questions** – Prepare for frequently asked technical interview questions.
- 📈 **Career Guidance** – Get recommendations for improving employability.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Placement-GPT.git
```

### 2. Navigate to the project directory

```bash
cd Placement-GPT
```

### 3. Install dependencies

For the frontend:

```bash
npm install
```

For the Python backend:

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

Create a `.env` file and add the required configuration:

```env
OPENAI_API_KEY=your_api_key
```

Never upload your API keys or other secrets to GitHub.

### 5. Run the application

Start the frontend:

```bash
npm run dev
```

Start the backend using the appropriate command for your framework.
